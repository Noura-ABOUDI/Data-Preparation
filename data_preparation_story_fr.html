Prologue · Introduction à la préparation des données

Le jeu de données qui ne voulait pas coopérer

Sami vient de rejoindre Fennec Express, une start-up de livraison basée à Sousse. L'équipe veut un modèle capable de prédire la durée de chaque livraison en minutes. Sami ouvre l'export de l'application : des enregistrements bruts, dont certains sont manifestement cassés. Aucun algorithme ne peut apprendre quoi que ce soit à partir de là.

La préparation des données consiste à nettoyer, formater, transformer et intégrer des données brutes afin de les rendre exploitables par un modèle. Elle influence directement la qualité du modèle final.

Mission 2 · Nettoyage des données

Corriger les quatre problèmes

Sami a repéré quatre problèmes : une ligne dupliquée, une distance manquante, un âge impossible et une durée de livraison qui ne peut pas être réelle. Appliquez chaque correction et regardez l'indicateur de santé des données monter.

Nettoyer en quatre étapes : supprimer les observations inutiles, traiter les valeurs manquantes (supprimer ou imputer), corriger les erreurs et filtrer les valeurs aberrantes. Les cellules vertes sont corrigées, les rouges demandent encore une action. La règle IQR signale toute valeur inférieure à Q1 − 1,5·IQR ou supérieure à Q3 + 1,5·IQR.
Voir le code du cours (diapositives 22, 24 à 26) 
df = df.drop_duplicates()
df_mean = df.fillna(df.mean())
df['Age'] = df['Age'].replace({-5: 35})

Q1 = df['Age'].quantile(0.25)
Q3 = df['Age'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['Age'] < Q1 - 1.5 * IQR) | (df['Age'] > Q3 + 1.5 * IQR))]

Mission 4 · Transformation des données

Même forme, nouvelle échelle

Les variables de Sami n'ont pas du tout la même échelle : l'une va jusqu'à 12 000, l'autre de 1 à 5. Les algorithmes qui mesurent des distances s'y perdent. Essayez les différents scalers et observez le déplacement des points.

Mise à l'échelle des variables

Remodeler une distribution asymétrique

Faites glisser le paramètre de puissance pour remodeler les distances de livraison, dont la distribution est asymétrique à droite.

Min-Max ramène les valeurs dans [0, 1] et est sensible aux valeurs aberrantes. Standard centre les données (moyenne 0, variance unitaire) et y est moins sensible. La formule de la diapositive 30 est X_new = (X − min) / (max − min). La transformation de puissance ci-dessus est une version simplifiée de Box-Cox ; le PowerTransformer(method='yeo-johnson') du cours gère aussi les valeurs négatives.
Voir le code du cours (diapositives 30 à 32) 
scaler = MinMaxScaler()
scaler.fit(X_train)                 # apprentissage sur l'entraînement uniquement
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)

Une image est une matrice de nombres

L'équipe véhicules et animaux de Fennec Express a besoin d'un classifieur qui répond à une question pour chaque photo : est-ce une voiture, un chat ou un chien ? Avant qu'un modèle puisse répondre, Sami doit savoir ce que voit réellement un ordinateur.

Chaque image est une grille de pixels. Un pixel couleur contient trois nombres : rouge, vert et bleu, chacun entre 0 et 255. Survolez l'image pour lire un pixel. L'image ci-dessous fait 24 × 24 pixels, agrandie pour que vous voyiez les carrés.

Mission 8 · Extraction de caractéristiques

Décrire chaque photo par la couleur, la forme et la texture

Les pixels bruts sont difficiles à exploiter directement. Sami extrait la description qu'un humain utiliserait : quelles couleurs dominent, quel contour dessine le sujet principal, et à quoi ressemble la surface.

Originale

Masque du sujet (forme)

Contours (texture)

Trois familles de caractéristiques : la couleur répond à la question « quelles couleurs ? » (moyennes rouge, vert, bleu, saturation) ; la forme répond à « où est le sujet et quel est son contour ? » (le masque montre les pixels qui diffèrent du fond, d'où la surface, le rapport d'aspect et la longueur du contour) ; la texture répond à « la surface est-elle chargée ? » (contraste, densité de contours et entropie des niveaux de gris).

import numpy as np
import pandas as pd

rgb = img.astype(float)                       # forme (24, 24, 3)
gris = rgb @ np.array([0.299, 0.587, 0.114])  # forme (24, 24)

# caractéristiques de couleur
mean_R, mean_G, mean_B = rgb.mean(axis=(0, 1)) / 255

# caractéristiques de forme : pixels différents de la couleur du fond
fond = np.concatenate([rgb[0], rgb[-1], rgb[:, 0], rgb[:, -1]]).mean(axis=0)
masque = np.linalg.norm(rgb - fond, axis=2) > 60
area_frac = masque.mean()

# caractéristiques de texture
densite_contours = (np.abs(np.diff(gris, axis=1)) > 40).mean()

ligne = {'mean_R': mean_R, 'area_frac': area_frac, 'edge_density': densite_contours}
pd.DataFrame([ligne]).to_csv('image_features.csv', index=False)

Séparation des classes (η²) est la part de la variance d'une caractéristique expliquée par l'étiquette (voiture, chat ou chien). Un score élevé signifie que la caractéristique aide à distinguer les classes. Évaluer chaque caractéristique seule, avant d'entraîner un modèle, est une méthode de filtrage, comme le SelectKBest basé sur l'ANOVA de scikit-learn.


  

    Voir le code de cette étape

from sklearn.feature_selection import VarianceThreshold, SelectKBest, f_classif

X = VarianceThreshold(threshold=1e-3).fit_transform(X)    # quasi constantes
corr = X.corr().abs()
upper = corr.where(np.triu(np.ones(corr.shape), k=1).astype(bool))
a_supprimer = [c for c in upper.columns if any(upper[c] > 0.95)]
X = X.drop(columns=a_supprimer)                            # redondantes

selector = SelectKBest(f_classif, k=5).fit(X, y)            # les 5 meilleures
X_selected = selector.transform(X)
