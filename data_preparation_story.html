Mission 2 · Data Cleaning

Fix the four problems

Sami found four problems: a duplicated row, a missing distance, an impossible driver age, and a delivery time that cannot be real. Apply each fix and watch the data health meter climb.

Cleaning in four moves: remove irrelevant observations, handle missing values (delete or impute), correct errors, and filter outliers. Green cells are fixed; red cells still need attention. The IQR rule flags any value below Q1 − 1.5·IQR or above Q3 + 1.5·IQR.
See the course code (slides 22, 24–26) 
df = df.drop_duplicates()
df_mean = df.fillna(df.mean())
df['Age'] = df['Age'].replace({-5: 35})

Q1 = df['Age'].quantile(0.25)
Q3 = df['Age'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['Age'] < Q1 - 1.5 * IQR) | (df['Age'] > Q3 + 1.5 * IQR))]

Mission 4 · Data Transformation

Same shape, new scale

Sami's features live on very different scales: one ranges up to 12,000, the other from 1 to 5. Algorithms that measure distance get confused. Try the scalers and see how the points move.

Feature scaling

Reshape a skewed distribution

Slide the power parameter to reshape the right-skewed delivery distances.

Min-Max maps values to [0, 1] and is sensitive to outliers. Standard gives mean 0 and unit variance and is less sensitive. The slide-30 formula is X_new = (X − min) / (max − min). The power transform here is a simplified Box-Cox; the course's PowerTransformer(method='yeo-johnson') also handles negative values.

Mission 7 · Computer Vision

An image is a matrix of numbers

The vehicle-and-pet team at Fennec Express needs a classifier that answers one question for each photo: is it a car, a cat or a dog? Before any model can answer, Sami has to know what a computer actually sees.

Every picture is a grid of pixels. A colour pixel stores three numbers: Red, Green and Blue, each from 0 to 255. Hover over the picture to read one pixel. The image below is 24 × 24 pixels, enlarged so you can see the squares.

Hover over the picture to read a pixel.

Show one channel as a matrix (values 0 to 255):

Matrix view: a 24 × 24 colour image is three 24 × 24 matrices stacked together (red, green, blue), so it holds 1,728 numbers. Grayscale keeps one matrix of 576 numbers. A real phone photo has millions of values, which is why the next missions summarise the image with features.

Mission 8 · Feature Extraction

Describe each photo by colour, shape and texture

Raw pixels are hard for a model to use directly. Sami extracts the kind of description people use: what colours the photo has, what outline the main subject makes, and how the surface looks.

Original

Subject mask (shape)

Edges (texture)

Three families of features: colour asks what colours the photo has (average red, green, blue and saturation); shape asks where the subject is and how its outline looks (the mask shows which pixels differ from the background, so area, aspect ratio and boundary length follow); texture asks how busy the surface is (contrast, edge density and entropy of the grayscale values).

import numpy as np
import pandas as pd

rgb = img.astype(float)                       # shape (24, 24, 3)
gray = rgb @ np.array([0.299, 0.587, 0.114])  # shape (24, 24)

# colour features
mean_R, mean_G, mean_B = rgb.mean(axis=(0, 1)) / 255

# shape features: pixels that differ from the background colour
bg = np.concatenate([rgb[0], rgb[-1], rgb[:, 0], rgb[:, -1]]).mean(axis=0)
mask = np.linalg.norm(rgb - bg, axis=2) > 60
area_frac = mask.mean()

# texture features
gx = np.abs(np.diff(gray, axis=1)).sum()
edge_density = (np.abs(np.diff(gray, axis=1)) > 40).mean()

row = {'mean_R': mean_R, 'area_frac': area_frac, 'edge_density': edge_density}
pd.DataFrame([row]).to_csv('image_features.csv', index=False)

Class separation (η²) is the share of a feature's variance explained by the label (car, cat or dog). A high score means the feature helps tell the classes apart. Scoring each feature alone, before training any model, is a filter method, like the ANOVA-based SelectKBest in scikit-learn.


  

    See the Python for this step

from sklearn.feature_selection import VarianceThreshold, SelectKBest, f_classif

X = VarianceThreshold(threshold=1e-3).fit_transform(X)    # drop near-constant
corr = X.corr().abs()
upper = corr.where(np.triu(np.ones(corr.shape), k=1).astype(bool))
to_drop = [c for c in upper.columns if any(upper[c] > 0.95)]
X = X.drop(columns=to_drop)                                # drop redundant

selector = SelectKBest(f_classif, k=5).fit(X, y)            # keep top 5
X_selected = selector.transform(X)
